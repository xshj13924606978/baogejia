## 实际修复

1. 迁移统一验收：将 G5 放到 fixture 重建之后；复制、刷新、聚合生成等失败必须阻断，字节/聚合不一致必须阻断。改动在 artifacts/scratch-review-r4 的两个验收脚本中。
2. 构建脚本：取消匹配 `_global-error` 文本即把失败当成功的逻辑；保留实际非零退出码。直接调用构建脚本也必须执行类型检查。
3. 构建恢复：恢复调用前 next-env.d.ts 的精确内容，避免 git checkout 覆盖用户未提交修改；原本不存在时移除生成文件。
4. 账号状态：数据库异常不再返回虚构的“账号存在且正常”状态；仅确认缺失 deleted_at 列时使用兼容查询，兼容查询失败同样拒绝继续。
5. 登录身份：OAuth/Bearer 分支校验软删除与账号可用状态；会话验证路由拒绝软删除账号，状态服务不可用返回 503。
6. 权限撤销：本地 token 授权使用数据库当前角色，避免管理员降级后沿用旧 token 的管理员权限；会话撤销判断不再将查询失败视为版本 0。
7. 用户同步：已有账号必须先证明所有权，不能仅凭邮箱/用户名进入写入或签发会话路径；用户同步及实时连接入口检查会话撤销。未在生产环境尝试利用；是否影响线上取决于生产版本。
8. 测试装置：修正过期的 maybeSingle mock、统一响应预期、延迟密钥校验预期；纯输入处理测试隔离不相关 OCR 服务依赖。
