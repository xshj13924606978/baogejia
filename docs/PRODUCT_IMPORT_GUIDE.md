# 产品价格库 Excel 导入功能说明

## 功能概述

产品价格库现已支持真正的Excel导入功能，包括：

- ✅ Excel文件解析（.xlsx, .xls, .csv）
- ✅ 自动上传到数据库
- ✅ 数据验证和错误处理
- ✅ 批量导入产品
- ✅ 手动添加产品
- ✅ 产品搜索
- ✅ 数据统计

## API 端点

### 1. 获取产品列表

```
GET /api/tables/products/list?keyword=xxx&page=1&limit=100
```

### 2. 导入产品

```
POST /api/tables/products/import
Content-Type: application/json

{
  "products": [
    {
      "产品名称": "工业提升泵",
      "型号": "CR5-12",
      "品牌": "格兰富",
      "规格": "流量12m³/h，扬程30m",
      "单位": "台",
      "价格": 3200,
      "供应商": "格兰富中国"
    }
  ]
}
```

### 3. 搜索产品

```
POST /api/tables/products/search
Content-Type: application/json

{
  "keyword": "提升泵"
}
```

## 使用方法

### 方法1：通过资料中心导入

1. 打开"报个价"应用
2. 点击底部工具栏的"📊 价格库"图标
3. 点击"📤 导入Excel"按钮
4. 选择要导入的Excel文件
5. 等待解析和导入完成
6. 查看导入结果（成功/失败数量）

### 方法2：手动添加产品

1. 打开"报个价"应用
2. 点击底部工具栏的"📊 价格库"图标
3. 点击"➕ 手动添加"按钮
4. 填写产品信息（至少填写产品名称和价格）
5. 点击"添加产品"按钮
6. 产品自动添加到列表中

### 方法3：下载模板

1. 打开"报个价"应用
2. 点击底部工具栏的"📊 价格库"图标
3. 点击"📥 下载模板"按钮
4. 系统自动下载"产品价格库模板.csv"文件
5. 使用模板填充数据后导入

## 数据验证规则

### 必填字段

- ✅ 产品名称
- ✅ 价格（必须大于0）

### 可选字段

- 型号
- 品牌/供应商
- 规格
- 单位（默认：台）
- 分类
- 描述
- 库存（默认：0）

## 导入结果

导入完成后，系统会显示：

- ✅ 成功导入的产品数量
- ❌ 失败的产品数量
- 📝 错误详情（如果有）

## 注意事项

1. **Excel格式**：支持.xlsx、.xls、.csv格式
2. **编码格式**：建议使用UTF-8编码（支持中文）
3. **列名匹配**：支持中英文列名，自动映射
4. **数据格式**：
   - 价格：数字格式（如：3200 或 3200.00）
   - 库存：整数格式（如：100）
   - 日期：YYYY-MM-DD格式
5. **必填字段**：产品名称和价格必须填写
6. **数据去重**：系统不会自动去重，相同产品会重复导入

## 错误处理

导入失败的可能原因：

1. 文件格式不正确
2. 必填字段缺失
3. 价格格式错误（非数字）
4. 数据库连接失败
5. 字符编码问题

## 常见问题

### Q: 导入后找不到产品？

A: 请检查产品列表的搜索关键词，或刷新页面重新加载。

### Q: 导入失败提示"数据格式不正确"？

A: 请确保Excel文件的第一行是列标题，且至少包含"产品名称"和"价格"列。

### Q: 中文字符显示乱码？

A: 请确保Excel文件使用UTF-8编码保存。

### Q: 如何批量修改产品信息？

A: 目前需要手动逐个修改，后续版本将支持批量编辑功能。
