**优化目标**:

## 问题分析

### 发现的问题
从日志中发现，虽然之前添加了去重逻辑，但返回的数据仍然使用 `specs` 字段而不是 `parameter_description` 字段：

```javascript
// 日志显示的字段（错误）
specs: 'PAM搅拌罐本体 φ4000×3000mm Q235B碳钢/壁厚 10mm；环氧树脂内外防腐/带顶盖及 活动加药孔；3条400mm支腿/不锈钢 304工艺管道 φ4000×3000套3 2'

// 期望的字段（正确）
parameter_description: 'PAM搅拌罐本体 φ4000×3000mm Q235B碳钢/壁厚 10mm；环氧树脂内外防腐/带顶盖及 活动加药孔；3条400mm支腿/不锈钢 304工艺管道 φ4000×3000套3 2'
```

### 问题根源
数据流分析：
```
PDF解析 → AI服务提取产品 → 返回 specs 字段 → 去重逻辑处理 → 返回给前端
```

**问题所在**：AI服务（`getCozeResponse` 和 `getTextInTableResponse`）在提取产品时使用的是 `specs` 字段名，而 `route.ts` 中的去重逻辑只是在现有数据基础上进行去重，没有转换字段名。

### 解决方案
在 `route.ts` 中添加字段名统一函数，在去重处理过程中自动将 `specs` 字段转换为 `parameter_description` 字段。

## 优化内容详解

### 1. 新增字段名统一函数
```typescript
/**
 * 统一字段名：将 specs 转换为 parameter_description
 * @param product 原始产品对象
 * @returns 字段名统一后的产品对象
 */
function normalizeFieldNames(product: any): any {
  const normalized = { ...product };

  // 如果存在 specs 字段且不存在 parameter_description 字段，则进行转换
  if (normalized.specs !== undefined && normalized.parameter_description === undefined) {
    normalized.parameter_description = normalized.specs;
    delete normalized.specs; // 删除旧字段名
  }

  return normalized;
}
```

**功能说明**：
- 检测产品对象中是否存在 `specs` 字段
- 如果存在且没有 `parameter_description` 字段，则进行转换
- 删除旧的 `specs` 字段，避免字段冗余
- 保留其他字段不变

### 2. 优化去重函数
在去重函数中集成字段名统一功能，确保每个产品在处理前都使用正确的字段名：

```typescript
function deduplicateProducts(products: any[]): any[] {
  if (!Array.isArray(products)) return products;

  const seen = new Map<string, boolean>();
  const uniqueProducts: any[] = [];

  for (const product of products) {
    // 先统一字段名
    const normalized = normalizeFieldNames(product);

    // 构建唯一键：使用 name, model 和 parameter_description（兼容新旧字段名）
    const paramDesc = normalized.parameter_description || normalized.specs || '';
    const key = `${normalized.name || ''}-${normalized.model || ''}-${paramDesc}`.trim();

    if (!seen.has(key)) {
      seen.set(key, true);
      uniqueProducts.push(normalized);
    }
  }

  // 记录去重信息（仅在开发环境或有调试需求时）
  if (process.env.NODE_ENV === 'development' && products.length !== uniqueProducts.length) {
    console.log(`[去重] 原始产品数: ${products.length}, 去重后: ${uniqueProducts.length}`);
  }

  return uniqueProducts;
}
```

**关键改进**：
- 在处理每个产品时，先调用 `normalizeFieldNames` 统一字段名
- 确保去重和返回的产品都使用 `parameter_description` 字段
- 保持兼容性，兼容新旧字段名

### 3. 数据流程
```
AI服务返回（specs字段）
    ↓
normalizeFieldNames() 转换
    ↓
parameter_description 字段
    ↓
去重处理
    ↓
返回给前端（parameter_description字段）
```

```typescript
// src/app/api/documents/parse/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { getServerSession } from 'next-auth';
import { authOptions } from '@/lib/auth';
import { getCozeResponse, getTextInTableResponse, uploadFileToTextIn } from '@/lib/ai-service';

/**
 * 统一字段名：将 specs 转换为 parameter_description
 * @param product 原始产品对象
 * @returns 字段名统一后的产品对象
 */
function normalizeFieldNames(product: any): any {
  const normalized = { ...product };

  // 如果存在 specs 字段且不存在 parameter_description 字段，则进行转换
  if (normalized.specs !== undefined && normalized.parameter_description === undefined) {
    normalized.parameter_description = normalized.specs;
    delete normalized.specs; // 删除旧字段名
  }

  return normalized;
}

/**
 * 根据name, model, parameter_description对产品列表进行去重
 * @param products 原始产品列表
 * @returns 去重后的产品列表
 */
function deduplicateProducts(products: any[]): any[] {
  if (!Array.isArray(products)) return products;

  const seen = new Map<string, boolean>();
  const uniqueProducts: any[] = [];

  for (const product of products) {
    // 先统一字段名
    const normalized = normalizeFieldNames(product);

    // 构建唯一键：使用 name, model 和 parameter_description（兼容新旧字段名）
    const paramDesc = normalized.parameter_description || normalized.specs || '';
    const key = `${normalized.name || ''}-${normalized.model || ''}-${paramDesc}`.trim();

    if (!seen.has(key)) {
      seen.set(key, true);
      uniqueProducts.push(normalized);
    }
  }

  // 记录去重信息（仅在开发环境或有调试需求时）
  if (process.env.NODE_ENV === 'development' && products.length !== uniqueProducts.length) {
    console.log(`[去重] 原始产品数: ${products.length}, 去重后: ${uniqueProducts.length}`);
  }

  return uniqueProducts;
}

export async function POST(request: NextRequest) {
  try {
    const session = await getServerSession(authOptions);
    if (!session?.user) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }

    const formData = await request.formData();
    const file = formData.get('file') as File | null;
    const parseType = formData.get('parseType') as string || 'auto';

    if (!file) {
      return NextResponse.json({ error: 'No file provided' }, { status: 400 });
    }

    // 将File对象转换为Buffer
    const bytes = await file.arrayBuffer();
    const buffer = Buffer.from(bytes);

    // 上传文件到TextIn
    const textInFileId = await uploadFileToTextIn(buffer, file.name);
    if (!textInFileId) {
      return NextResponse.json({ error: 'Failed to upload file to TextIn' }, { status: 500 });
    }

    let result;

    // 根据解析类型选择不同的解析策略
    if (parseType === 'auto') {
      // 先尝试TextIn表格解析
      try {
        const textInResult = await getTextInTableResponse(textInFileId);
        if (textInResult && textInResult.products && textInResult.products.length > 0) {
          result = textInResult;
        } else {
          // TextIn未解析出内容，使用Coze Vision
          throw new Error('TextIn returned empty result');
        }
      } catch (textInError) {
        console.log('TextIn parsing failed, falling back to Coze Vision:', textInError);
        const cozeResult = await getCozeResponse(textInFileId);
        result = cozeResult;
      }
    } else if (parseType === 'textin') {
      // 强制使用TextIn
      result = await getTextInTableResponse(textInFileId);
    } else {
      // 强制使用Coze
      result = await getCozeResponse(textInFileId);
    }

    // ==================== 优化点：对结果进行去重 ====================
    if (result && result.products && Array.isArray(result.products)) {
      result.products = deduplicateProducts(result.products);
    }
    // ==============================================================

    return NextResponse.json(result);
  } catch (error) {
    console.error('Document parse error:', error);
    return NextResponse.json(
      { error: 'Failed to parse document' },
      { status: 500 }
    );
  }
}
```
