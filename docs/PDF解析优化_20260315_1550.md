# PDF解析功能优化 - 版本记录

**版本名称**: PDF解析优化_20260315_1550
**优化日期**: 2026年3月15日 15:50
**优化目标**: 修复 parameter_description 字段返回 undefined 的问题

## 问题分析

### 发现的问题
从日志中发现，Coze Vision 解析返回的数据中没有正确填充 `parameter_description` 字段：
```
[QuoteTable] 第一个产品的 parameter_description: undefined
```

### 问题根源
1. **Coze Vision 的 prompt 没有强制要求提取 `parameter_description` 字段**
2. **缺少字段映射逻辑**：当 Coze 返回旧字段名（如 specs、description）时，没有自动映射到新字段名

## 修改文件列表
1. `src/lib/ai-service.ts`（新建）

## 优化内容详解

### 1. 创建 AI 服务集成文件
创建了完整的 AI 服务集成文件，包含三个核心服务：
- **Coze Vision**: 使用视觉理解能力解析PDF
- **TextIn**: 专门针对表格数据的解析
- **文件上传服务**: 上传文件到 TextIn

### 2. 增强 Coze Vision Prompt
在发送给 Coze 的 prompt 中，明确要求 `parameter_description` 字段：
- 在【输出格式要求】中明确列出该字段
- 添加说明："这是最重要的字段！必须从文件中提取完整的参数信息"
- 增加【重要规则】第1条："parameter_description 必须填充，不能为空！"

### 3. 添加字段映射逻辑
在解析 Coze 返回数据时，确保 `parameter_description` 字段存在：
```typescript
parameter_description: p.parameter_description || p.specs || p.description || p.parameters || ''
```

这样即使 Coze 返回的是旧字段名（specs/description/parameters），也能正确映射到新字段。

/**
 * AI服务集成
 * 
 * 提供PDF解析功能，支持多种AI服务：
 * - Coze Vision: 使用视觉理解能力解析PDF
 * - TextIn: 专门针对表格数据的解析

// ============================================================================
// 类型定义
// ============================================================================

export interface Product {
  name: string;
  model: string;
  brand: string;
  parameter_description: string;
  quantity: number;
  unit: string;
  unit_price: number;
  remark: string;
}

export interface ParseResult {
  products: Product[];
}

// ============================================================================
// Coze Vision 服务
// ============================================================================

/**
 * 使用 Coze Vision 解析PDF文件
 * @param fileId TextIn 文件ID
 * @returns 解析后的产品列表
 */
export async function getCozeResponse(fileId: string): Promise<ParseResult> {
  try {
    const response = await fetch('https://api.coze.cn/v1/workflow/run', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${process.env.COZE_API_KEY}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        workflow_id: process.env.COZE_WORKFLOW_ID,
        parameters: {
          file_id: fileId,
          // ==================== 优化点：增强 Prompt ====================
          prompt: `你是一个专业的PDF解析助手，请从上传的文件中提取产品信息。

【输出格式要求】
必须返回一个JSON对象，包含products数组，每个产品必须包含以下字段：
- name: 产品名称（必须）
- model: 型号规格（如果没有则填空字符串）
- brand: 品牌（如果没有则填空字符串）
- parameter_description: 产品的详细参数描述（这是最重要的字段！必须从文件中提取完整的参数信息，如果没有则从specifications或描述中提取）
- quantity: 数量（如果没有则填1）
- unit: 单位（如果没有则填"套"）
- unit_price: 单价（数字，如果没有则填0）
- remark: 备注（如果没有则填空字符串）

【重要规则】
1. parameter_description 必须填充，不能为空！
2. 如果文件中有重复的产品，请只保留一条
3. 参数描述要完整、详细
4. 严格按照上述字段名返回

请开始解析。`,
          // ==============================================================
        },
      }),
    });

    const data = await response.json();
    
    // 解析 Coze 返回的数据
    if (data.code === 0 && data.data) {
      try {
        const result = JSON.parse(data.data);
        
        // ==================== 优化点：字段映射 ====================
        if (result.products && Array.isArray(result.products)) {
          result.products = result.products.map((p: any) => ({
            name: p.name || '',
            model: p.model || '',
            brand: p.brand || '',
            // 确保 parameter_description 字段存在，支持多种旧字段名
            parameter_description: p.parameter_description || p.specs || p.description || p.parameters || '',
            quantity: p.quantity || 1,
            unit: p.unit || '套',
            unit_price: p.unit_price || 0,
            remark: p.remark || ''
          }));
        }
        // ==============================================================
        
        return result;
      } catch (e) {
        console.error('解析Coze返回数据失败:', e);
        return { products: [] };
      }
    }
    
    return { products: [] };
  } catch (error) {
    console.error('Coze API调用失败:', error);
    return { products: [] };
  }
}

// 文件上传服务
// ============================================================================

/**
 * 上传文件到 TextIn
 * @param fileBuffer 文件内容（Buffer）
 * @param fileName 文件名
 * @returns TextIn 文件ID
 */
export async function uploadFileToTextIn(fileBuffer: Buffer, fileName: string): Promise<string | null> {
  try {
    const formData = new FormData();
    formData.append('file', new Blob([fileBuffer]), fileName);
    
    const response = await fetch('https://api.textin.com/api/v3/ocr/upload', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${process.env.TEXTIN_API_KEY}`,
      },
      body: formData,
    });
    
    const data = await response.json();
    
    if (data.code === 200 && data.file_id) {
      return data.file_id;
    }
    
    return null;
  } catch (error) {
    console.error('文件上传到TextIn失败:', error);
    return null;
  }
}
